# V43 sandbox subscription access and credit simulation
Candidate only, separate from existing private-beta AI. No paid features or real AI unlocked. Default-disabled endpoint verifies existing private operator identity, fetches subscription references from service-only V42 ledger, checks current Stripe subscription and invoice, fails closed on foreign ownership, incomplete/unpaid/expired state, provider error, or multiple non-terminal subscriptions. Bounded history: more than five distinct subscriptions requires manual review. Ledger only contains observed subscriptions; it cannot establish that there are no unobserved duplicates. Before production require trusted customer mapping and atomic checkout lifecycle, complete Stripe reconciliation, subscription change/refund/dispute handling and production entitlement policy. Test credit limits are provisional: Starter 30/month, 5/day, text only; Professional 100/month, 15/day, text 1 credit/photo 3. UTC calendar periods, per-account counters across plan changes. Candidate service-only SQL uses an account advisory lock and unique request IDs; duplicate reservation rejected, not replayed as success. No AI calls by simulation. SQL unexecuted; mock tests do not prove SQL concurrency or grants. Requires V42 SQL, V43 SQL and real ACL/concurrency tests before deployment. No production plan limits implemented. Global AI spend caps and existing beta usage remain unchanged.
