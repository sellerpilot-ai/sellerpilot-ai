# V41 private Stripe-hosted sandbox checkout
V40 read-only Stripe price verification passed on device on 24 Nov 2026. V41 adds a separate authenticated private operator function, disabled by existing SELLERPILOT_STRIPE_ENABLED=false. Only GBP monthly fixed server prices, card test checkout, test key, exact hosted checkout origin/path, explicit test consent. Idempotency applies to retry of the same request ID; separate requests can create separate test subscriptions. No production access grants, no card data collected by SellerPilot. A returned session is verified via Stripe API and account ownership, not trusted from a browser redirect; no access granted even after paid sandbox result. Return verification is deliberately not a durable billing ledger or renewal verification. Webhook signature verification, persistent customer/subscription mapping, duplicate subscription prevention, cancellation/renewal reconciliation and entitlement/quota enforcement remain next release gates. Keep flag false until these are ready for controlled testing. No live keys or real payments. Stripe docs: https://docs.stripe.com/api/checkout/sessions/create ; https://docs.stripe.com/api/checkout/sessions/retrieve ; https://docs.stripe.com/api/idempotent_requests .
