# V37 privacy controls — first increment
- Verified account workspace export includes current synced catalogue, audit history, research, editorial preferences and shortlist. No authentication/session tokens exported by design; arbitrary user content may itself contain sensitive data and should be treated as private.
- Request-file workflow only; no submission, deletion or provider action occurs. Account deletion is intentionally not activated until verified identity, database dependencies, session revocation, provider data handling, retention exceptions and operator contact are reviewed.
- Public pre-launch information reflects live restricted text AI, gated photo AI and Etsy data permission requirement.
- Before launch: verified operator and support contact, formal data rights/retention workflow, full account deletion with reauthentication and explicit confirmation, two-account isolation and deletion tests using disposable accounts, review leaked-password protection, verify final legal notice.
- No new services or paid calls.
