# V35 — opt-in automatic catalogue health snapshots

On successful authenticated catalogue sync, enabled accounts capture one snapshot per UTC week using existing listing quality rules. Existing snapshot is never overwritten automatically. Manual save remains available. Opt-in defaults off; preference is private and cloud-backed. No new tables, AI spend, marketplace data, scheduled email or background job. No reports for missed weeks or empty catalogues. Writes use existing optimistic concurrency check; failures are retried on a subsequent sync, not in a loop. History capped at 16 weeks. Test uses mock data and simulates prior-week snapshot. True closed-browser scheduling remains a separate future task, requiring a server-side scoring worker and verified schedule/privacy controls.
